# Выбор embedding-модели (Б5.1)

## Как сравнивали

`tests/eval/mini_benchmark.json` — 8 троек *(вопрос пользователя, нужный фрагмент, похожий-но-неверный фрагмент)*
из домена «Финпомощника»: вычеты, страхование вкладов, подушка безопасности, мошенничество, кредиты,
экспорт в приложении, правило 50/30/20, налог на проценты. Неверные фрагменты — **из того же домена**
(вычет за лечение против вычета за квартиру), иначе тест был бы слишком лёгким. Вопросы — разговорные,
«не теми словами», что в документе: «банк лопнул что будет с моим вкладом», «на чёрный день».

Метрики: в скольких тройках `cos(вопрос, нужный) > cos(вопрос, неверный)`; средний и **минимальный** зазор
между ними (минимальный показывает самую рискованную пару). Все модели — через один и тот же
OpenAI-совместимый `/v1/embeddings` (Ollama, RTX 4070 SUPER), с прогревом. Скрипт: `scripts/embedding_benchmark.py`.

## Результаты (2026-10-12)

| Модель | Язык | Размерность | Верно | Зазор ср. | Зазор мин. | мс/текст |
|---|---|---|---|---|---|---|
| **qwen3-embedding 0.6B** + инструкция к запросу | мульти | 1024 | **8/8** | **+0.238** | **+0.099** | ~130 |
| qwen3-embedding 0.6B без инструкции | мульти | 1024 | 8/8 | +0.202 | +0.036 | 131 |
| bge-m3 | мульти | 1024 | 8/8 | +0.128 | +0.023 | 686 |
| nomic-embed-text | англ. | 768 | **7/8** | +0.058 | **−0.017** | 144 |

- nomic ошиблась на «сколько денег держать на чёрный день»: англоязычная модель не связала идиому с
  «подушкой безопасности». Вывод: **для русского корпуса — только мультиязычные модели**.
- bge-m3 справилась, но с вдвое меньшим запасом и в 5 раз медленнее.
- **Облачные модели** (`openai/text-embedding-3-small`, `baai/bge-m3` через OpenRouter) — флаг `--cloud`;
  _будут добавлены в таблицу после получения ключа OpenRouter._

## Асимметрия: инструкция к запросу (аналог `query:` / `passage:` у E5)

qwen3-embedding — instruction-aware модель. К **запросу** добавляется
`Instruct: Given a user question about personal finance, retrieve the passage that answers it\nQuery: …`,
**документы** кодируются без префикса (`embed_query` / `embed_documents` в `app/services/embeddings.py`).
Smoke-тест на том же mini-benchmark: без инструкции минимальный зазор **+0.036**, с инструкцией **+0.099** —
самая трудная пара перестаёт быть «на грани».

## Решение: `qwen3-embedding:0.6b`, локально через Ollama

| Критерий | Почему подходит |
|---|---|
| Язык | Лучший результат на русских разговорных вопросах |
| Размерность | 1024 — компромисс «качество / память Qdrant» (для 100k чанков ≈ 400 МБ float32) |
| Стоимость | $0: модель работает на своём GPU, ~130 мс на текст |
| Приватность | Тексты финансовых документов и вопросы пользователей **не уходят** внешнему провайдеру |
| Риск | Нужен Ollama рядом с сервисом. Запасной путь — `baai/bge-m3` через OpenRouter ($0.01 / 1M токенов): смена `EMBEDDING_BASE_URL` / `EMBEDDING_MODEL` **и переиндексация** (векторы разных моделей несовместимы) |

## Стоимость индексации 50+ документов

Корпус Б5.5 — ~60 документов × ~700 токенов ≈ **42 000 токенов** (фрагменты mini-benchmark в среднем
103 токена; документы длиннее). Индексация одна, повторный прогон — из дискового кеша.

| Модель | Токенов | Стоимость |
|---|---|---|
| qwen3-embedding 0.6B (Ollama, наш выбор) | 42 000 | **$0** |
| baai/bge-m3 (OpenRouter) | 42 000 | $0.0004 |
| openai/text-embedding-3-small | 42 000 | $0.0008 |
| openai/text-embedding-3-large | 42 000 | $0.0055 |

Деньги на индексацию в любом случае копеечные; решающими были качество на русском и приватность.

## Сервис `app/services/embeddings.py`

- `embed_texts(texts)` — батчи по 64, таймаут 60 с + ретраи SDK, L2-нормализация (cosine == dot);
- дисковый кеш `var/embeddings_cache` с ключом `model + sha256(text)`. Проверка — CLI дважды:

```
$ python -m app.services.embeddings "Как получить налоговый вычет за лечение?" "Сколько держать на подушку?"
model=qwen3-embedding:0.6b dim=1024 texts=2 api_calls=1 cache_hits=0 time=2236.4 ms
$ python -m app.services.embeddings "Как получить налоговый вычет за лечение?" "Сколько держать на подушку?"
model=qwen3-embedding:0.6b dim=1024 texts=2 api_calls=0 cache_hits=2 time=0.2 ms
```

- смена модели в `.env` → другой ключ кеша (старые векторы не подмешиваются); несовпадение размерности
  с `EMBEDDING_DIM` → понятная ошибка, а не тихая порча индекса. Тесты — `tests/unit/test_embeddings.py`.
